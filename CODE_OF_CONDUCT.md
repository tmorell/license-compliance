# Code of Conduct

`license-compliance` uses the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. We don't reproduce the full text here to avoid maintaining a stale copy; please read the [official version](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) for the complete pledge, standards of behavior, scope, and enforcement guidelines (the escalation ladder from a private correction through to a permanent ban). Translations are available from [contributor-covenant.org/translations](https://www.contributor-covenant.org/translations).

This Code of Conduct applies across all project spaces, issues, pull requests, discussions, and any other official project channels, as well as when someone is representing the project in public spaces.

---

## Reporting & Confidentiality

### Reporting an Incident

If you experience or witness unacceptable behavior, or have any other concerns, please report it directly to the project maintainer:

- **Contact Email**: [teomorell@gmail.com](mailto:teomorell@gmail.com)

Project maintainers aim to:

- **Confidentiality**: Handle all reports with strict confidentiality regarding the identity of the reporter and anyone implicated.
- **Timely Response**: Acknowledge reports within 48 hours, with investigation and appropriate action to follow. Conduct reports are given a longer initial window than technical/security reports (see [`SECURITY.md`](SECURITY.md)) because they typically require careful, unhurried handling rather than a fast technical triage.
- **Fairness**: Respect the privacy and security of the reporter of any incident and conduct fair, unbiased reviews.

`license-compliance` is maintained on a best-effort, largely solo basis, these are the targets we hold ourselves to, not a guaranteed SLA. If you haven't heard back within the acknowledgment window, a polite follow-up is always welcome.
